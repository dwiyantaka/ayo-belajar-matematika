# Direktori Ilustrasi Soal

Simpan berkas gambar ilustrasi soal di dalam folder ini (format yang didukung: `.png`, `.webp`, `.jpg`, `.jpeg`, `.svg`).

Nama berkas yang dimasukkan pada editor soal di Akses Guru (misal: `P-01.png`, `klepon-3x5.webp`) akan otomatis dimuat dari direktori ini saat soal ditampilkan di permainan **Hitung Jajan**.
